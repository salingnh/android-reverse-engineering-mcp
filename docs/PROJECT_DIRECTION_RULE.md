# Project Direction Documentation Rule

This project treats repository documentation as the durable source of truth for long-term direction.

Whenever a substantial architectural, analyzer-routing, security-boundary, product-priority, or AI-agent decision changes, update in the same change:

1. `docs/PROJECT_DIRECTION.md` — canonical product and architecture direction;
2. `docs/ROADMAP.md` — priorities, implementation status, phases, and acceptance criteria;
3. `README.md` — concise current development focus visible to users;
4. relevant research/design documents when new technical evidence is introduced.

Do not rely on chat history alone to preserve project intent.
